# 問いから読み続ける体験の改善

2026-10-03。対象は `noemap/noemap.com` の PR #4。確認用の変更で、本番反映は別途指示を受ける。

## 変更

- 紙に近い背景、濃い青の文字、明朝の見出し、余白を用いた入口。8テーマの並び・スマホ2列・PC4列・行直後の展開を維持。
- 「迷ったら、この問いから」の一問と、実際の記事を結ぶ番号付き読書ルート。
- 「別の問いに出会う」で現在公開中の問いを切り替える。直前と同じ問いを選ばず、選んだUUIDをURLに保存。戻る操作や再読み込みでも復元し、下書き・撤回された項目は候補に含めない。
- 問いの記事では「この問いの見方」を本文より先に表示。公開済み概念の題名・要約と、実際の関係の理由または読書上の目的を案内する。
- 「次の発見へ」で既出カードを除き、関連する問い・概念・人物・著作を案内。編集上の読書ルートと歴史的な影響関係を区別する説明を保持。
- 参照資料は資料名・参照箇所を見せ、著者・版の情報を開いて読める形式へ。同じ資料の複数の参照箇所を上書きせず、すべて保持する。
- 検索は検索語を主役にして、種類・テーマ・学問の条件を折りたたむ。条件適用時は開き、件数を表示。条件解除でも検索語を保持。結果が空でも問い・テーマから探索を続けられる。
- ホームから問い・概念・人物・著作への移動で入口と位置を記録。記事の入口リンクとブラウザーの戻る操作で復元。直接の記事アクセスでは種類に応じた一覧へのリンクを表示。
- 44px以上の主要操作領域、キーボードのフォーカス、読み上げへの問い切り替え通知、動きを減らす設定への対応。

本文・出典・編集上の限定を削除せず、表示順と密度を調整した。現在の36公開項目を利用し、準備中5テーマの仮記事、個人保存、AI、課金機能は追加していない。

## 確認

- 最終ビルドと型チェック成功。整形チェック成功。
- 入口データ10項目、公開データ32項目が成功。入口HTTP9項目、公開サイトHTTP10項目が成功。
- 全36記事の描画と、88の参照情報に含まれる参照箇所・引用表記・版・帰属・根拠URLの保持を確認。
- 実ブラウザーで320・390・768・1280pxのホームを確認。2列／4列と横のはみ出しがないことを確認。320pxの検索と390pxの記事でも横のはみ出しがない。
- Enterで小テーマを開く、3操作で実記事へ進む、ブラウザーで戻ってテーマ・小テーマを復元する操作を確認。
- 別の問いへ切り替えたあと、実記事から戻ると選んだ問いと展開状態が復元される。
- 適用中の検索条件を閉じて送信しても条件を保持。条件解除後も検索語を保持。結果が空の場合の代替リンクを確認。

HTTPの記録は `docs/validation/entry-http.json`。作業端末にはPC・スマホ・読書画面の画像を保存した。
