# 入口デザインの実装・確認記録

2026-10-03。対象: `noemap/noemap.com`。既存の公開36記事・出典・関係・DB・編集認証を維持し、入口と探索導線を変更。本番公開は別途指示が必要で、この変更はPRで確認する。

## 実装した範囲

- 「人間とは何か。」から8枚の大テーマへ。600px以下で2列、それより広い画面で4列。
- 大テーマのカードを含む行の直後に小テーマを表示。小テーマの直下に公開済みの問いへのリンクと概要リンクを表示。末端は既存の個別URLへ直接進む。
- 同階層の切り替え、再押下で閉じる、キーボード、aria-expanded、フォーカス表示。
- 開閉状態をURLに保存。入口から記事への移動時に同一タブ内へ位置を記録し、戻る操作と記事内の入口リンクで復元。30分で期限切れ。個人ノートや会員保存とは異なる。
- 共通のTheme・Discipline・EntryGroup・UUIDによる分類。テーマ一覧・詳細、人物・概念の探索、名前・別名・要約と種類・テーマ・分野の検索。
- 「私は同じ私なのか？」→「人格同一性（ヒューム）」→「人格同一性（ロック）」→「忘れても私は同じ私なのか？」の編集上の読書ルート。記事でも次のページを選べる。歴史的な影響関係とは区別。
- 記事の要約・分類・編集日、記事ごとの題名・説明・正規URL・OG情報、現在の公開記事だけの動的サイトマップ。局所マップと読み上げ用一覧、出典と関係の理由は既存の共通データを維持。
- 入口・検索・読書ルートは現在の匿名公開投影だけを使用。入口の参照が残っていても下書き・撤回記事を復活させない。

現在の資料で問いを案内できるテーマは「こころと意識」「自分と他者」「知識と真実」。ほかの5テーマは「準備中」。参考HTMLの仮本文は導入していない。心理学等の分野分類は追加できるが、記事を制作済みとは表示しない。

## 検証

- ビルド・型チェック成功。入口データ10項目、既存公開データ32項目、公開投影・永続保存・編集47項目が成功。
- ローカルHTTPで入口7項目、既存公開サイト10項目が成功。全36記事のURL・証拠・一覧・英語別名・年代・非公開編集ページの制限を確認。
- 320・390px: カード2列、展開は選択カードの行直後、小テーマのリンクは次の小テーマより前。768・1280px: 4列、同じ順序。いずれも横のはみ出しなし。
- 実ブラウザーで小テーマをEnterで開閉し、兄弟グループとテーマの切り替えを確認。
- スマホの「こころと意識」→「変わっても、同じ自分？」→実記事を3操作で表示。記事からブラウザーで戻るとURL `/?theme=mind&group=identity`、両項目の開いた状態、移動時の位置231pxを復元。再読み込み後の記事と入口へのリンクでも復元。
- 記事の更新はタイトル・本文・出典を維持。検索結果が空の場合もテーマを変えて続けられる。
- 出典撤回で入口の問い・概要・グループが消えること、公開データが空の場合に記事リンクを生成しないことを試験。

HTTP記録: `docs/validation/entry-http.json`。実画面のスクリーンショットとブラウザーの確認記録は作業端末に保存。
